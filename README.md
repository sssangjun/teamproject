# re:pick 중고거래 사이트

## 프로젝트 소개

- 사용자가 중고 상품을 등록하고 거래할 수 있는 웹사이트입니다.
- 제작 목적 : Git을 사용한 협업 능력 강화 및 프론트엔드, 백엔드 개발 역량 향상

## 주요 기능
- 회원가입 및 로그인, 비밀번호 찾기
- 회원정보 수정
- 상품 등록, 수정 및 삭제
- 상품 검색 및 카테고리, 지역 검색
- 상품 조회 및 상세보기
- 찜 기능
- 신고 기능
- 채팅 기능
- 관리자 회원 관리 및 신고 관리

## 기술 스택
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP
- Database: MariaDB
- Server: Apache
- Collaboration: Git, Github

## 담당 역할 — @sssangjun

프론트엔드 및 UI/UX 구현을 중심으로 PHP 데이터를 화면에 연동하는 작업을 담당했습니다. 아래 내용은 팀 프로젝트에서 제가 담당한 구현 범위입니다.

### 1. 회원 관련 화면

- 회원가입 및 회원가입 완료 화면 구현
- 회원정보 수정 화면 구현 및 디자인 개선
- 비밀번호 찾기 화면을 HTML에서 PHP로 전환하고, 비밀번호 변경 화면과 페이지 이동 경로 개선
- 마이페이지 및 다른 회원 프로필 화면 구현
- 판매 중인 상품과 판매 완료 내역 표시
- 회원 신고 및 거래 별점 평가 화면 구현

### 2. 상품 관련 화면

- 상품 등록 화면 초안 및 가격·지역 입력 UI 구현
- 상품 상세 페이지 UI 및 상품 수정 화면의 사용자 경험 개선
- 마이페이지의 판매 중인 상품 목록과 전체보기 페이지 구현
- 상품 카드에 가격, 거래 상태, 지역 정보 표시

### 3. 채팅 및 거래 화면

- 채팅방 목록 및 개별 채팅방 화면 구현
- 최근 메시지, 상대방 정보, 상품 정보 표시
- 읽지 않은 메시지 수를 배지로 표시
- 이미지 메시지 출력 오류 수정
- 거래 결제 화면 구현
- 신고 사유, 상세 내용, 증거 이미지 입력 화면 구현
- 거래 완료 후 별점 및 후기 작성 화면 구현

### 4. 메인 화면 및 공통 UI

- 프로젝트 로고와 파비콘 적용
- 메인 배너 이미지 및 슬라이드 구성
- 최근 등록 상품과 카테고리 영역 디자인
- 상품 카드 디자인 및 버튼 UI 개선
- 상단 메뉴, 검색창, 카테고리 메뉴 배치 개선
- 로그인 상태에 따른 로그인·로그아웃 메뉴 표시 구현
- 마이페이지, 찜 목록, 채팅 메뉴 연결
- 푸터 정보 및 공통 글꼴·색상 스타일 정리
- 반응형 레이아웃과 Bootstrap 기반 UI 개선

### 5. 목록 및 페이지네이션

- 검색 결과 페이지네이션 디자인 개선
- 찜 목록 및 카테고리 상품 목록 페이지네이션 구현
- 페이지당 상품 수 제한 및 페이지 이동 UI 제공
- 상품 정렬 및 목록 화면 디자인 개선

### 6. 관리자 화면

- 관리자 회원정보 수정 화면 정리
- 관리자 로그인 페이지를 PHP 화면으로 전환
- 메인 화면에서 관리자 페이지로 이동할 수 있는 링크 추가

### 사용 기술

HTML5, CSS3, JavaScript, Bootstrap 5, PHP, MariaDB, Git/GitHub
